Use this in every page:

function siteFooter() {
  return `
  <footer class="site-footer">
    <div class="footer-inner">
      <div class="footer-brand">Breto's Services</div>

      <div class="footer-copy">© 2026 Breto's Services · Todos los derechos reservados</div>

  </footer>`;
}

CSS:
.site-footer{
  margin-top:auto;
  padding:24px 16px;
  border-top:1px solid var(--border);
  text-align:center;
}
.footer-inner{max-width:600px;margin:0 auto}
.footer-brand{font-weight:700;font-size:.95rem;margin-bottom:4px}
.footer-tag{font-size:.8rem;color:var(--muted);margin-bottom:8px}
.footer-copy{font-size:.72rem;color:var(--muted);opacity:.8}

Also ensure .main uses display:flex; flex-direction:column; min-height so footer sticks to bottom.
